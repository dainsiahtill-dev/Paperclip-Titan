# Phaser 像素办公室

用户明确要求改用 Phaser，办公室和 NPC 动作通过游戏画布渲染；外围继续使用现有 React 页面。V3 为视觉基准，所有房门朝南，部门随汇报关系生成。本次授权覆盖早先不用 Canvas 的限制。

1. 锁定 Phaser 3.90.0，复用已验收的环境 PNG、NPC 动作和二十人站/坐关键姿势。NPC 会话保持独立源文件所有权；办公室只更新公开运行复制品与自己的验收证据。
2. 保留已修复的公司边界、实际员工/当前任务阶段、排队后继与额度重试语义；不触发员工执行，不改数据库、模型或服务。
3. 新建像素坐标场景模型：参考图房间比例、紧凑工位、中央茶水角、两排横廊和贯通入口。碰撞只计算地面占位，所有门验证可达；工位 ID 坐标稳定，扩容重算路径。
4. Phaser 单一动画时钟与相机；人物按脚底 Y 排序，四向动态帧按实际 foot/hip 元数据定位。桌前沿、椅背、扶手和头部独立层，不把人物或家具烘焙成固定公司背景。
5. 所有色彩、字号、尺寸、运动参数从 index.css token 读取；像素资源保持原 RGBA，不绘制替代人物。镜像使用已验收 effective anchor，反放按已提供数组顺序。
6. 实际浏览器先验证 Canvas、素材加载与遮挡，再逐项对照 V3 的人物/桌椅比例、房间宽高、装饰、茶水角、室外区域；同时验证状态变化、员工点击、暂停动画、缩放、移动端及减少动画。
7. 跑相关逻辑测试、UI 类型检查/build 和 token gates。完整仓库测试此前有单独复验通过但完整套件未结束的记录，不例行重跑大套件、不宣称全库全绿。不 git pull/stash/提交，不启停服务。
